# Mascot prompts for Grok Image

The main pose (`chef-main.png`) is done. These prompts make the other poses of the **same** character.

**How to keep him identical:** upload `chef-main.png` as the reference image with each prompt.
Each prompt also describes him in full, in case the reference is not used.

Save the results in this folder:

| File | Used for |
|---|---|
| `chef-wave.png` | Lock screen / welcome |
| `chef-thinking.png` | "AI is working…" screens |
| `chef-happy.png` | Success messages ("Meal saved", "Plan applied") |
| `chef-pointing.png` | Empty lists ("No items yet") — optional |

Format: PNG with transparent background, portrait 2:3 like the main image (e.g. 768 × 1152).
If Grok gives a solid background instead, that is fine — I remove it.

---

```
NEW POSE: waving hello. Right hand raised high and open, palm towards the viewer, fingers spread in a friendly wave. Left hand resting on the hip. Big warm welcoming smile with eyes bright and open. Slight head tilt. No spoon in this image.

Full body visible from hat to shoes, centred, facing the viewer at a slight three-quarter angle, small margin around the character. Portrait format 2:3.

BACKGROUND: fully transparent background, PNG with alpha channel, character isolated with clean edges. If transparency is not possible, use a plain solid light cream background (#FEF8F0) with nothing else.

AVOID: no text, no letters, no logo, no watermark, no props, no floor, no scenery, no drop shadow on the background, no extra characters, no cropped hat or feet, no change to the face or outfit.
```
